# Tecnologías y herramientas

| Tecnología | Uso |
|---|---|
| Python 3.10+ | Lógica de simulación |
| Tkinter | Interfaz de escritorio prevista |
| HTML5 | Maqueta visual del panel |
| CSS3 | Diseño adaptable |
| JavaScript | Interacciones de demostración |
| JSON | Registro local de eventos |
| Matplotlib (opcional) | Gráficas |
| Git / GitHub | Control de versiones |
| Visual Studio Code | Edición y depuración |

## Requisitos estimados
- Computador de doble núcleo o superior.
- 4 GB RAM recomendados.
- Windows 10/11 o Linux.
- Python 3.10+ para el prototipo.
- Navegador moderno para la maqueta.
