# Descripción del proyecto

CyberShield es una aplicación didáctica para simular el monitoreo y la administración de procesos de un sistema operativo. La herramienta permite observar procesos ficticios, consumo estimado de recursos y alertas de seguridad.

## Necesidad
Facilitar la comprensión práctica de procesos, planificación, gestión de CPU y memoria, concurrencia y monitoreo de seguridad.

## Objetivo
Desarrollar una aplicación de escritorio que simule el monitoreo de procesos y la detección de comportamientos sospechosos en un entorno controlado.

## Alcance
La solución utiliza exclusivamente procesos y métricas simuladas; no inspecciona ni modifica procesos reales y no ejecuta malware.
