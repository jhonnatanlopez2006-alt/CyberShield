# Requerimientos

## Funcionales
| ID | Requerimiento |
|---|---|
| RF-01 | Crear procesos ficticios. |
| RF-02 | Mostrar PID, nombre, estado, prioridad, CPU y memoria. |
| RF-03 | Pausar y reanudar procesos simulados. |
| RF-04 | Finalizar procesos simulados. |
| RF-05 | Alertar ante umbrales simulados de CPU o memoria. |
| RF-06 | Identificar patrones anómalos ficticios. |
| RF-07 | Ejecutar escenarios predefinidos. |
| RF-08 | Registrar eventos y alertas. |
| RF-09 | Mostrar estadísticas y gráficas. |

## No funcionales
| ID | Requerimiento |
|---|---|
| RNF-01 | Interfaz clara y fácil de usar. |
| RNF-02 | Código modular y mantenible. |
| RNF-03 | Mensajes de alerta comprensibles. |
| RNF-04 | Compatibilidad prevista con Windows 10/11 y Linux. |
| RNF-05 | No interactuar con procesos reales ni ejecutar malware. |
| RNF-06 | Guardar eventos en un formato legible como JSON. |
| RNF-07 | Documentar instalación y ejecución. |
